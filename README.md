## Overview

Blue Cat FreqAnalyst provides accurate real-time spectrum analysis with the ability to compare multiple instances simultaneously, making EQ decisions across tracks easy and precise.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Blue Cat FreqAnalyst** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Instance** | Compare spectra from different tracks in one plugin window |
| **Resolution** | Adjustable FFT resolution from 256 to 65536 points |
| **Peak Hold** | Configurable peak hold trace for identifying spectral hot spots |
| **Averaging** | Spectrum averaging modes for smooth, stable frequency display |
